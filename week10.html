useState Hook

ทำให้ Component "จำค่า" ได้ — เมื่อค่าเปลี่ยน UI อัปเดตอัตโนมัติ

🤔 ทำไมต้องมี State?
❌ ตัวแปรธรรมดา — UI ไม่อัปเดต
// ❌ นี่ไม่ work const Counter = () => { let count = 0 return ( <div> <p>{count}</p> <button onClick={() => count++}> เพิ่ม </button> </div> ) } // กดปุ่ม count เพิ่ม // แต่หน้าจอไม่เปลี่ยน! 😱
✅ useState — UI อัปเดตอัตโนมัติ
// ✅ ใช้ useState import { useState } from 'react' const Counter = () => { const [count, setCount] = useState(0) return ( <div> <p>{count}</p> <button onClick={() => setCount(count + 1)}> เพิ่ม </button> </div> ) } // กดปุ่ม → count เพิ่ม → UI อัปเดต ✓
🔑 React รู้ว่าต้อง render ใหม่เมื่อไหร่ก็ต่อเมื่อเรียก setter function (setCount) — ถ้าแก้ตัวแปรตรงๆ React ไม่รู้ ไม่ render ใหม่
📖 Syntax — อ่านและจำให้ขึ้นใจ
const [value, setValue] = useState(initialValue) // ตัวอย่างจริง const [count, setCount] = useState(0) const [name, setName] = useState("") const [isOpen, setIsOpen] = useState(false) const [liked, setLiked] = useState(false) const [items, setItems] = useState([]) // JS ที่ใช้: Array Destructuring // useState คืน array [ค่าปัจจุบัน, ฟังก์ชันอัปเดต]
แยกทีละส่วน:
[ value ]
ค่าปัจจุบัน — ใช้ใน JSX เพื่อแสดงผล
[ setValue ]
ฟังก์ชันอัปเดต — เรียกเพื่อเปลี่ยนค่า React จะ render ใหม่อัตโนมัติ
useState(initial)
ค่าเริ่มต้น — number, string, boolean, array, object ได้ทั้งหมด
📝 ตั้งชื่อ: count + setCount, name + setName — ใช้ set นำหน้าเสมอ

Event Handler

รับ input จากผู้ใช้ — กดปุ่ม พิมพ์ข้อความ เลื่อน mouse และอื่นๆ

📋 Events ที่ใช้บ่อย
Event (JSX)เมื่อไหร่ใช้กับตัวอย่าง
onClick คลิก element button, div, img onClick={() => setCount(count+1)}
onChange พิมพ์/เปลี่ยนค่า input, select, textarea onChange={(e) => setText(e.target.value)}
onSubmit กด Submit ใน form form onSubmit={(e) => e.preventDefault()}
onMouseEnter hover เข้า ทุก element onMouseEnter={() => setHover(true)}
onMouseLeave hover ออก ทุก element onMouseLeave={() => setHover(false)}
✍️ วิธีเขียน Event Handler
// แบบที่ 1 — inline arrow function // เหมาะกับ logic สั้นๆ <button onClick={() => setCount(count + 1)}> เพิ่ม </button> // แบบที่ 2 — แยก function // เหมาะกับ logic ยาว / ใช้หลายที่ const handleClick = () => { setCount(count + 1) console.log('กดแล้ว!') } <button onClick={handleClick}>เพิ่ม</button> // ⚠️ onClick={handleClick} ไม่ใส่ ()
// onChange กับ input const [text, setText] = useState("") <input value={text} onChange={(e) => setText(e.target.value)} /> // e คือ Event Object // e.target คือ element // e.target.value คือค่าที่พิมพ์ <p>พิมพ์: {text}</p>
⚠️ onClick={"{"}handleClick{"}"} ไม่มี () — ถ้าใส่ handleClick() จะเรียก function ทันทีตอน render ไม่ใช่ตอนกด

"ซ่อน" : "ดูรายละเอียด"} </button> {showDesc && <p className="text-sm text-gray-500">รายละเอียด...</p>} {/* Like button */} <button onClick={handleLike} className={liked ? "text-red-500" : "text-gray-400"}> {liked ? "❤️" : "🤍"} {likes} </button> </div> ) }
