Array .map()

แปลงทุก item ใน array ให้เป็นอะไรก็ได้ — คืน array ใหม่ที่มีขนาดเท่ากัน

🗺️ .map() คืออะไร?
❌ แบบเดิม — วน loop ด้วย for
const nums = [1, 2, 3] const doubled = [] for (let i = 0; i < nums.length; i++) { doubled.push(nums[i] * 2) } console.log(doubled) // [2, 4, 6]
✅ .map() — สั้นและชัดกว่ามาก
const nums = [1, 2, 3] const doubled = nums.map((n) => n * 2) console.log(doubled) // [2, 4, 6] // .map() ต้อง return ค่าเสมอ // คืน array ใหม่ — ไม่แก้ array เดิม
💡 .map() วนทุก item แล้ว return ค่าใหม่ เสมอ — ต่างจาก forEach ที่ไม่ return อะไร
📦 .map() กับ Array of Objects
const menuData = [ { id:1, name:"ลาเต้", price:80 }, { id:2, name:"อเมริกาโน่", price:65 }, { id:3, name:"บราวนี่", price:65 }, ] // ดึงแค่ชื่อ const names = menuData.map((item) => item.name) // ["ลาเต้", "อเมริกาโน่", "บราวนี่"] // แปลงเป็น string แสดงราคา const labels = menuData.map((item) => `${item.name} ฿${item.price}` ) // ["ลาเต้ ฿80", "อเมริกาโน่ ฿65", ...]
// .map() + destructuring const names = menuData.map( ({ name, price }) => `${name} ฿${price}` ) // เพิ่มราคา 10 ทุกอัน const newPrices = menuData.map((item) => ({ ...item, price: item.price + 10 })) // [{id:1, name:"ลาเต้", price:90}, ...]
⚠️ return object ใน .map() ต้องครอบด้วย ( ) — .map((item) => ({'{'} ...item {'}'})) ไม่งั้น JS คิดว่าเป็น function body

Array .filter()

กรองเฉพาะ item ที่ตรงเงื่อนไข — คืน array ใหม่ที่สั้นลง

🔍 .filter() คืออะไร?
const menuData = [ { name:"ลาเต้", price:80, cat:"เครื่องดื่ม" }, { name:"อเมริกาโน่", price:65, cat:"เครื่องดื่ม" }, { name:"บราวนี่", price:65, cat:"ขนม" }, { name:"วาฟเฟิล", price:75, cat:"ขนม" }, ] // เฉพาะเครื่องดื่ม const drinks = menuData.filter( (item) => item.cat === "เครื่องดื่ม" ) // [{name:"ลาเต้",...}, {name:"อเมริกาโน่",...}] // เฉพาะราคาไม่เกิน 70 const cheap = menuData.filter( (item) => item.price <= 70 )
// .filter() + .map() รวมกัน — ใช้บ่อยมาก menuData .filter((item) => item.cat === "ขนม") .map((item) => ( <MenuCard key={item.id} {...item} /> )) // 1. filter กรองเฉพาะขนม // 2. map แปลงแต่ละอันเป็น <MenuCard />
🔥 .filter().map() คือ combo ที่ใช้บ่อยที่สุดใน React — filter หมวดหมู่ แล้ว map render

List Rendering ใน React

ใช้ .map() ใน JSX — render ทุก item อัตโนมัติ

⚛️ .map() ใน JSX — ก่อน vs หลัง
❌ แบบเดิม Week 9 — copy-paste
// App.jsx — ถ้ามี 10 เมนู = 10 บรรทัด return ( <div className="grid grid-cols-3 gap-6"> <MenuCard {...menuData[0]} /> <MenuCard {...menuData[1]} /> <MenuCard {...menuData[2]} /> {/* เพิ่มเมนูต้องแก้ที่นี่ทุกครั้ง 😩 */} </div> )
✅ ใช้ .map() — ไม่ว่ากี่อันก็ทำได้
// App.jsx — เพิ่มข้อมูลใน array แค่นั้น return ( <div className="grid grid-cols-3 gap-6"> {menuData.map((item) => ( <MenuCard key={item.id} {...item} /> ))} </div> ) // เพิ่มเมนูใน array → แสดงอัตโนมัติ ✓
🔑 key prop — สำคัญมาก อย่าลืม!
// ❌ ไม่มี key — Warning ใน console menuData.map((item) => ( <MenuCard {...item} /> )) // ✅ มี key — ถูกต้อง menuData.map((item) => ( <MenuCard key={item.id} {...item} /> )) // ถ้าไม่มี id ใช้ index ได้ (แต่ไม่แนะนำ) menuData.map((item, index) => ( <MenuCard key={index} {...item} /> ))
key คืออะไร?
React ใช้ key ระบุว่า item ไหนคือตัวเดิม เมื่อ list เปลี่ยน React จะ update เฉพาะที่เปลี่ยนจริงๆ
กฎของ key
✓ ต้อง unique ในกลุ่มเดียวกัน
✓ ใช้ id จากข้อมูลจริง ดีที่สุด
✗ ห้ามใช้ random / Math.random()
✗ ไม่ต้อง pass เป็น prop ลง Component
🚨 ถ้าลืม key จะเห็น Warning สีเหลืองใน Console — ไม่ error แต่ทำให้ React ทำงานช้าและ bug ยาก
